# OA办公管理系统
仓库地址：https://github.com/GUORUI-929/oa

## 一、项目简介
本项目是基于SpringBoot搭建的企业后端OA办公系统，面向企业员工、部门管理者、财务等多角色，实现员工管理、考勤打卡、请假审批、发票文件上传、费用报销等核心办公业务，完整后端分层项目，可用于简历项目展示、Java后端练习。

## 二、核心技术栈
- 开发语言：Java
- 核心框架：Spring Boot
- 持久层：MyBatis
- 数据库：MySQL
- 项目构建：Maven
- 工具：Lombok、本地文件上传存储

## 三、主要功能模块
1. 用户权限管理：基础登录、账号权限区分
2. 员工信息管理：员工信息CRUD维护
3. 考勤管理：员工打卡记录管理
4. 审批流程：请假申请、流程审批逻辑
5. 发票上传模块：本地图片文件上传、存储预览
6. 费用报销：报销单录入、明细管理

## 四、项目目录结构
oa
├── .mvn/wrapper Maven 构建工具
├── src 核心业务源码
│ ├── main/java Java 业务代码（Controller/Service/Mapper/Entity）
│ └── main/resources 配置文件、Mapper 映射文件
├── upload/invoice 上传发票图片存储目录
├── pom.xml Maven 依赖配置
└── README.md 项目说明文档

## 五、本地启动步骤
1. 环境准备：安装JDK、MySQL
2. 创建MySQL数据库，导入对应业务数据表
3. 修改resources内数据库配置文件，填写自己的数据库账号密码
4. 使用IDEA打开项目，刷新Maven依赖
5. 运行启动类，访问本地端口8080即可调试接口
